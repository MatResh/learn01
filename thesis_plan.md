## 1. ПОСТАНОВКА ЗАДАЧИ ОПТИМИЗАЦИИ

### 1.1 Цель работы
Разработать систему автоматизированной оптимизации геометрических параметров ступени паровой турбины с использованием методов машинного обучения для повышения эффективности и снижения времени проектирования.

### 1.2 Объект исследования
Одноступенчатая паровая турбина (рабочее колесо и направляющий аппарат).

### 1.3 Предмет исследования
Зависимость эффективности ступени (КПД, потери энергии, распределение давления) от геометрических параметров лопаточного аппарата.

### 1.4 Критерии оптимизации
**Главный критерий:**
- Максимизация КПД ступени (η)

**Дополнительные ограничения:**
- Минимизация потерь давления
- Обеспечение механической прочности (напряжения в допустимых пределах)
- Ограничение по массовому расходу пара
- Предотвращение кавитации и отрывных течений

## 2. ОПРЕДЕЛЕНИЕ ПАРАМЕТРОВ ОПТИМИЗАЦИИ

### 2.1 Входные параметры (7 ключевых параметров)

#### Параметры рабочего колеса:
1. **Угол установки лопатки на входе (β₁)** 
   - Диапазон: 20° - 45°
   - Влияние: определяет направление входа потока
   - Шаг дискретизации: 2.5°

2. **Угол установки лопатки на выходе (β₂)**
   - Диапазон: 15° - 35°
   - Влияние: определяет поворот потока
   - Шаг дискретизации: 2°

3. **Угол закрутки лопатки (twist angle, θ)**
   - Диапазон: 0° - 25°
   - Влияние: распределение нагрузки по высоте лопатки
   - Шаг дискретизации: 2.5°

#### Параметры направляющего аппарата:
4. **Угол установки сопловых лопаток (α₁)**
   - Диапазон: 12° - 25°
   - Влияние: скорость и направление потока на входе в РК
   - Шаг дискретизации: 1.5°

5. **Хорда лопатки (c)**
   - Диапазон: 0.8 - 1.2 относительно базового значения
   - Влияние: прочность и аэродинамическое качество
   - Шаг дискретизации: 0.05

#### Геометрические параметры профиля:
6. **Максимальная толщина профиля (t_max/c)**
   - Диапазон: 0.08 - 0.15 (относительная толщина)
   - Влияние: прочность и потери
   - Шаг дискретизации: 0.01

7. **Шаг решетки (s/c - относительный шаг)**
   - Диапазон: 0.6 - 1.0
   - Влияние: загромождение потока и потери
   - Шаг дискретизации: 0.05

### 2.2 Выходные параметры (целевые функции)

**Основные выходы:**
- КПД ступени (η) - главная целевая функция
- Потери полного давления (ΔP₀/P₀)
- Коэффициент расхода (φ)
- Степень реактивности (ρ)

**Дополнительные выходы (для анализа):**
- Распределение статического давления
- Поле скоростей
- Максимальные напряжения (для оценки прочности)

## 3. МЕТОДОЛОГИЯ РАБОТЫ

### 3.1 Этап 1: Подготовка данных (2-3 дня)

#### День 1-2: Настройка AxStream и генерация базовой модели
1. Создать базовую геометрию ступени в AxStream
2. Валидировать модель на известных режимах работы
3. Определить граничные условия:
   - Параметры входа: давление, температура, расход
   - Параметры выхода: статическое давление
   - Частота вращения ротора

#### День 2-3: Генерация обучающего датасета
**Стратегия сбора данных:**

**Вариант A: Latin Hypercube Sampling (LHS)**
- Преимущества: равномерное покрытие пространства параметров
- Количество симуляций: 200-300 расчетов
- Время расчета: ~2-3 минуты на расчет = 10-15 часов общего времени
- Запуск: автоматизировать через Python скрипт + AxStream API

**Вариант B: Комбинированный подход**
- Начальный грубый DOE (Design of Experiments): 100 точек
- Дополнительные расчеты в областях с высоким градиентом КПД: 50-100 точек
- Всего: 150-200 расчетов

**Параллелизация:**
- Запустить несколько экземпляров AxStream (если позволяет лицензия)
- Использовать batch processing
- Оптимизация: начать с грубой сетки, затем уточнить

#### День 3: Предобработка данных
1. Очистка данных:
   - Удаление некорректных расчетов (не сошедшиеся решения)
   - Проверка физической корректности результатов
2. Нормализация параметров:
   - Min-Max scaling для входных параметров
   - Стандартизация выходных параметров
3. Анализ корреляций:
   - Построение матрицы корреляций
   - Выявление наиболее влияющих параметров
4. Разделение на обучающую/валидационную/тестовую выборки (70%/15%/15%)

### 3.2 Этап 2: Разработка ML моделей (3-4 дня)

#### День 4-5: Построение суррогатных моделей

**Модель 1: Random Forest Regressor**
- Причина выбора: устойчивость к выбросам, не требует нормализации
- Гиперпараметры для настройки:
  - n_estimators: 100, 200, 500
  - max_depth: 10, 20, None
  - min_samples_split: 2, 5, 10
- Преимущества: интерпретируемость (feature importance)

**Модель 2: Gradient Boosting (XGBoost/LightGBM)**
- Причина выбора: высокая точность на табличных данных
- Гиперпараметры:
  - learning_rate: 0.01, 0.05, 0.1
  - n_estimators: 100, 300, 500
  - max_depth: 3, 5, 7
- Преимущества: быстрое обучение и предсказание

**Модель 3: Нейронная сеть (MLP)**
- Архитектура: 
  - Входной слой: 7 нейронов (входные параметры)
  - Скрытые слои: [64, 32, 16] или [128, 64, 32]
  - Выходной слой: 1 нейрон (КПД) или 4 нейрона (все целевые функции)
- Функция активации: ReLU в скрытых слоях, Linear в выходном
- Оптимизатор: Adam
- Преимущества: способность моделировать нелинейные зависимости

**Модель 4: Gaussian Process Regression (опционально)**
- Причина: предоставляет оценку неопределенности
- Использование: для активного обучения и выбора новых точек для симуляции

#### День 5-6: Обучение и валидация моделей
1. Обучение моделей с кросс-валидацией (k-fold, k=5)
2. Подбор гиперпараметров:
   - Grid Search или Random Search
   - Или Bayesian Optimization для более быстрого подбора
3. Оценка качества моделей:
   - R² score (коэффициент детерминации) > 0.95
   - Mean Absolute Error (MAE)
   - Root Mean Squared Error (RMSE)
   - Mean Absolute Percentage Error (MAPE) < 2%
4. Сравнение моделей и выбор лучшей

#### День 6-7: Анализ важности признаков
1. Feature Importance из Random Forest
2. SHAP (SHapley Additive exPlanations) values
3. Partial Dependence Plots (PDP)
4. Выводы о влиянии каждого параметра на КПД

### 3.3 Этап 3: Оптимизация (3-4 дня)

#### День 7-8: Реализация алгоритмов оптимизации

**Метод 1: Генетический алгоритм (GA)**
```python
Параметры GA:
- Размер популяции: 50-100
- Количество поколений: 100-200
- Вероятность кроссовера: 0.8
- Вероятность мутации: 0.1
- Селекция: турнирная или ранговая
```
Преимущества: глобальный поиск, не требует градиентов

**Метод 2: Particle Swarm Optimization (PSO)**
```python
Параметры PSO:
- Количество частиц: 30-50
- Количество итераций: 100-150
- Инерционный вес: 0.7
- Когнитивный коэффициент: 1.5
- Социальный коэффициент: 1.5
```
Преимущества: быстрая сходимость, простота реализации

**Метод 3: Bayesian Optimization**
- Acquisition function: Expected Improvement (EI) или Upper Confidence Bound (UCB)
- Итерации: 50-100
Преимущества: эффективен при малом количестве оценок функции

**Метод 4: Gradient-based (опционально)**
- L-BFGS-B или SLSQP с ограничениями
- Требует дифференцируемой модели (нейронная сеть)

#### День 8-9: Запуск оптимизации
1. Запуск всех методов оптимизации
2. Сравнение результатов:
   - Найденный максимум КПД

   - Количество оценок целевой функции
3. Анализ оптимальных параметров
4. Проверка результатов в AxStream (валидация)

#### День 9: Multi-objective оптимизация (опционально)

## 5. МЕТРИКИ УСПЕХА И КРИТЕРИИ ОЦЕНКИ

### 5.1 Критерии успешности ML моделей
- **R² > 0.95**: модель хорошо предсказывает КПД
- **MAPE < 2%**: средняя относительная ошибка меньше 2%
- **Время предсказания < 0.01 с**: быстрые вычисления для оптимизации

### 5.2 Критерии успешности оптимизации
- **Улучшение КПД**: прирост минимум на 1-2% относительно базовой конфигурации

- **Время оптимизации**: < 5 минут (против часов CFD-оптимизации)
