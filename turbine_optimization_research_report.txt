1. ПРОГРАММНЫЙ ПАКЕТ AXSTREAM - ВОЗМОЖНОСТИ И ФУНКЦИОНАЛЬНОСТЬ
───────────────────────────────────────────────────────────────────────────

1.1 Основные возможности AxStream (SoftInWay):
   • Полный цикл проектирования турбомашин (flow path geometry)
   • 1D и 2D анализ производительности
   • Интеграция CFD и FEA для мультидисциплинарной оптимизации
   • Детальный термо-гидравлический анализ систем
   • Параметрические исследования и автоматическая оптимизация
   • Реверс-инжиниринг существующих геометрий профилей
   • Расчет характеристик потока при различных геометрических параметрах

1.2 Практические преимущества для задачи:
   • Готовая среда для вариации параметров геометрии
   • Возможность автоматизации расчетов через API/скрипты
   • Быстрый 1D/2D анализ для генерации обучающих данных
   • Встроенные инструменты параметризации лопаток


2. ПАРАМЕТРЫ ОПТИМИЗАЦИИ СТУПЕНИ ПАРОВОЙ ТУРБИНЫ
───────────────────────────────────────────────────────────────────────────

2.1 Геометрические параметры лопатки:

   A. ПРОФИЛЬНЫЕ ПАРАМЕТРЫ:
      • Угол установки лопатки (stagger angle)
      • Угол входа потока (inlet angle)
      • Угол выхода потока (outlet angle)
      • Толщина профиля в различных сечениях
      • Радиус передней кромки (leading edge radius)
      • Радиус задней кромки (trailing edge radius)
      • Кривизна профиля (camber)
      • Хорда профиля (chord length)

   B. ТРЕХМЕРНЫЕ ПАРАМЕТРЫ:
      • Закрутка лопатки (blade twist) - изменение угла от корня до периферии
      • Наклон лопатки (blade lean) - радиальный наклон
      • Осевой наклон (sweep)
      • Высота лопатки (blade height)
      • Количество лопаток в венце (blade count)

   C. КАСКАДНЫЕ ПАРАМЕТРЫ:
      • Шаг лопаток (pitch/spacing)
      • Зазоры (clearances)
      • Радиальное распределение параметров

2.2 Целевые функции для оптимизации:
   • Эффективность ступени (stage efficiency)
   • Потери энергии (aerodynamic losses)
   • Коэффициент расхода (mass flow coefficient)
   • Степень реактивности (reaction degree)
   • Распределение нагрузки по высоте лопатки
   • Минимизация вторичных потоков


3. АКТУАЛЬНОСТЬ И ПРАКТИЧЕСКАЯ ПОЛЬЗА ОПТИМИЗАЦИИ
───────────────────────────────────────────────────────────────────────────

3.1 Экономическая выгода:
   • Повышение КПД на 1-2% = существенная экономия топлива
   • Увеличение мощности при тех же габаритах
   • Снижение динамических напряжений = увеличение срока службы
   • Уменьшение потерь энергии в турбине

3.2 Научная актуальность:
   • ML позволяет исследовать огромное пространство параметров
   • Сокращение времени оптимизации в 10^5 раз vs традиционных методов
   • Возможность найти неочевидные оптимальные конфигурации
   • Применение современных подходов к классической инженерии


4. СТРАТЕГИЯ: ПРОФИЛЬ vs ПОЛНАЯ ЛОПАТКА
───────────────────────────────────────────────────────────────────────────

РЕКОМЕНДАЦИЯ: Начать с оптимизации ПРОФИЛЯ лопатки

4.1 Преимущества работы с профилем:
   ✓ Меньшая размерность задачи (5-15 параметров)
   ✓ Быстрее расчеты в AxStream (2D vs 3D CFD)
   ✓ Проще интерпретация результатов
   ✓ Можно сгенерировать больше данных за 2 недели
   ✓ Меньшие требования к вычислительным ресурсам
   ✓ Легче валидация результатов

4.2 Когда переходить к полной лопатке:
   • После успешной оптимизации профиля
   • При наличии дополнительного времени
   • Для учета 3D эффектов (twist, lean)
   • При необходимости точной оценки реальной эффективности


5. МЕТОДЫ ПАРАМЕТРИЗАЦИИ ПРОФИЛЯ
───────────────────────────────────────────────────────────────────────────

5.1 Вариант 1: Кривые Безье (РЕКОМЕНДУЕТСЯ ДЛЯ НАЧАЛА)
   
   Параметры: 8-12 контрольных точек
   
   Преимущества:
   • Простая и интуитивная система
   • Малое количество параметров (4-6 точек на сторону профиля)
   • Хорошо подходит для ML-оптимизации
   • Легко реализовать в Python
   • Гарантия гладкости кривой
   
   Недостатки:
   • Менее гибкая, чем B-splines
   • Глобальные изменения при движении контрольной точки
   
   Реализация:
   - Верхняя поверхность: 4-5 контрольных точек Безье
   - Нижняя поверхность: 4-5 контрольных точек Безье
   - Фиксированные точки: передняя и задняя кромки
   - ИТОГО: ~8-10 параметров (координаты контрольных точек)

5.2 Вариант 2: B-Splines (NURBS)
   
   Параметры: 10-15 контрольных точек
   
   Преимущества:
   • Локальный контроль формы
   • Большая гибкость геометрии
   • Точное моделирование сложных форм
   
   Недостатки:
   • Больше параметров = больше симуляций
   • Сложнее в реализации
   • Требует больше данных для обучения ML
   
   Рекомендация: Использовать на втором этапе после Безье

5.3 Вариант 3: Гибридная параметризация (ОПТИМАЛЬНЫЙ)
   
   Комбинация базовых геометрических параметров + Безье:
   
   Параметры (7-9 переменных):
   1. Угол установки (stagger angle)
   2. Угол входа (inlet angle)
   3. Угол выхода (outlet angle)
   4. Хорда профиля (chord)
   5. Максимальная толщина (max thickness)
   6. Кривизна (camber) - через 2-3 точки Безье для тонкой настройки
   7. Радиус передней кромки
   8. Радиус задней кромки
   
   Преимущества:
   • Баланс между простотой и гибкостью
   • Инженерный смысл параметров
   • Оптимальное число параметров для 2-недельного проекта

6. АРХИТЕКТУРА ML-СИСТЕМЫ (2 НЕДЕЛИ)
───────────────────────────────────────────────────────────────────────────

6.1 Этап 1 (Дни 1-3): Подготовка данных
   
   • Настройка автоматизации AxStream
   • Генерация датасета: 200-500 симуляций
   • Latin Hypercube Sampling для охвата пространства параметров
   • На Ryzen 7 5700U: ~2-5 мин на 2D расчет = 500 точек за 2-3 дня
   
6.2 Этап 2 (Дни 4-7): Построение surrogate модели
   
   Рекомендуемые модели:
   
   A. Feedforward Neural Network (простая, быстрая):
      - Архитектура: 8-10 входов → 64 → 32 → 16 → 1-3 выхода
      - Время обучения: 10-30 минут на CPU
      - Точность: R² > 0.95 при 300+ примерах
      
   B. Gaussian Process (надежная, с uncertainty):
      - Хорошо работает с малыми данными (100-200 точек)
      - Предоставляет оценку неопределенности
      - Время обучения: 5-20 минут
      
   C. Random Forest (baseline):
      - Быстрое обучение
      - Хорошая интерпретируемость
      - Время: 1-5 минут
   
   Рекомендация: Начать с Random Forest, затем FNN

6.3 Этап 3 (Дни 8-10): Оптимизация
   
   Методы:
   • Genetic Algorithm (GA) - надежный, популяционный
   • Particle Swarm Optimization (PSO) - быстрый
   • Bayesian Optimization - эффективный с малым бюджетом
   
   Вычислительная сложность: 1000-10000 оценок surrogate модели = секунды
   
6.4 Этап 4 (Дни 11-14): Валидация и финализация
   
   • Проверка 10-20 лучших решений в AxStream
   • Анализ чувствительности
   • Сравнение с базовым дизайном
   • Подготовка отчета и презентации

10. РИСКИ И МИТИГАЦИЯ
───────────────────────────────────────────────────────────────────────────

Риск 1: Медленные расчеты в AxStream
Решение: Начать с 2D моделей, использовать упрощенные сетки, 
         параллельные расчеты если возможно

Риск 2: Недостаточно данных для ML
Решение: Использовать Gaussian Processes (хорошо работают с малыми данными),
         активное обучение (active learning)

Риск 3: Сложность параметризации
Решение: Начать с гибридного подхода (7-9 параметров),
         постепенно усложнять если время позволит

Риск 4: Нереалистичные геометрии
Решение: Ввести физические ограничения (constraints) в оптимизацию,
         проверка feasibility перед расчетом
